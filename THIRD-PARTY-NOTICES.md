# Third-party components

MouseBridge's original source is MIT licensed. Dependencies retain their own licenses.

Windows self-contained binaries include Microsoft .NET 8 Windows Desktop Runtime (MIT and third-party components), C#/WinRT (MIT), and Windows SDK .NET projections (Microsoft package terms). See runtime notices below and the package metadata resolved by NuGet. Test-only xUnit (Apache-2.0) and Microsoft.NET.Test.Sdk are not shipped in the runtime EXE.

macOS links Apple system frameworks (AppKit, IOBluetooth, ApplicationServices, QuartzCore); these are supplied by macOS, not redistributed here. Building requires Apple's development tools and SDK under their respective terms.

Bundled runtime attribution text is embedded as application resources and retained in source under notices/. No dependencies are relicensed by the MouseBridge MIT license.
