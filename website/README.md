# Public bilingual download website

Buildless HTML/CSS/JS, no analytics, trackers, cookies or account system. English: index.html; Korean: ko/index.html. The small desk demo illustrates crossing/indicator settings and is explicitly not a live desktop connection.

Copy the release's Windows/Mac/source ZIPs, SHA256SUMS.txt and TEST-RESULTS.md into downloads/ and LICENSE into LICENSE.txt before deployment. Local-link validation expects those artifacts. Sites hosting configuration is maintained in the deployment checkout rather than this public source snapshot. No access tokens or runtime secrets belong in this directory.
