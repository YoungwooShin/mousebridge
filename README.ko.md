# MouseBridge

**블루투스로 두 컴퓨터의 키보드·마우스와 텍스트 클립보드를 공유합니다.** 통신에 같은 와이파이, 인터넷, VPN, 중계 서버가 필요하지 않습니다.

[English](README.md) · [한글 사이트 / 다운로드](https://youngwooshin.github.io/mousebridge/ko/) · [MIT 라이선스](LICENSE) · [테스트 결과](TEST-RESULTS.md)

## 다운로드와 지원 범위

[배포 사이트](https://youngwooshin.github.io/mousebridge/ko/#downloads)에서 Windows0.3.0 / Mac0.3.2를 받습니다.

- **Windows ↔ Windows:** 기존 시제품. 무설치 ZIP에 `MouseBridge.exe` 하나만 있습니다. 새 경계 표시 UI는 실제 Windows 확인이 필요합니다.
- **Mac ↔ Windows, Mac ↔ Mac:** 양쪽 역할을 구현한 실험적 Mac 포트입니다. Apple silicon·Intel 통합 앱의 네이티브 CI 빌드와 임시 서명 검사를 통과했으나, 실제 Mac 실행·블루투스·입력 동작은 아직 검증하지 못했습니다.
- 소스 ZIP과 SHA-256 체크섬도 제공합니다. Windows는 서명되지 않았고, Mac은 임시 서명으로 Developer ID 서명·Apple 공증이 없습니다. 운영체제의 정상 확인 절차를 사용하고 보안 기능을 끄지 마세요.

## Windows 사용법

1. 시스템 블루투스 설정에서 두 컴퓨터를 페어링하고 양쪽 앱을 실행합니다.
2. 받는 쪽은 **Secondary PC**, 키보드·마우스를 연결한 쪽은 **Main PC**를 누릅니다.
3. 메인의 **Screen arrangement**에서 화면 카드를 드래그해 좌우를 정하고 **Save screen settings**를 누릅니다.
4. 맞닿은 화면 경계의 **가운데 80%**로 이동하면 상대 화면 반대쪽으로 넘어갑니다. 상대적인 높이를 유지하며 위아래 10%는 제외합니다. 키·버튼을 누른 동안에는 자동으로 넘어가지 않습니다.
5. **F8**로도 전환·복귀합니다. Windows 메인의 **Switch shortcut**에서 바꿀 수 있습니다.
6. 복사 → 전환 → 붙여넣기로 일반 텍스트를 양쪽으로 전달합니다. 최대 256KiB UTF-8이며 파일·이미지·서식은 지원하지 않습니다.
7. 최소화해도 실행을 유지합니다. **Stop**은 제어와 자동 재연결을 중단하며 닫으면 종료합니다.

## 경계 표시 디자인

화면 안쪽으로 흐려지는 그라데이션, 얇은 색상선, 위아래 페이드를 적용했습니다. 각 Windows PC에서 폭 **8–120px**(기본 50), 불투명도 **0–100%**, 추천 색상 6개·HEX·색상 선택기를 사용할 수 있습니다. 미리보기로 확인하고 저장하세요. 표시를 끄거나 불투명도를 0으로 하면 숨깁니다. 클릭·포커스를 가로채지 않도록 구현했으며 실제 Windows 렌더링·DPI 확인은 필요합니다.

## Mac 사용법과 차이

macOS 13 이상에서 압축을 풀어 `MouseBridge.app`을 Applications로 옮기고, 블루투스·**손쉬운 사용**·메인의 **입력 모니터링** 권한을 허용합니다. 페어링한 후 세컨더리를 먼저 실행하세요. Mac 메인에서는 장치를 선택하고 **Connect / reconnect**를 누릅니다. Mac 수신기는 연결마다 상대 제어 승인을 묻습니다.

Mac은 현재 F8 고정, 수동 재연결, 좌우 선택 메뉴를 사용합니다. 경계 표시는 기본 파란색이며 Windows와 같은 표시 편집 UI는 없습니다. 클립보드 수신 완료를 기다린 뒤 붙여넣으세요. Mac Command와 Windows Ctrl을 대응시키지만 한영 전환·다른 키 배열·앱별 단축키는 실제 시험이 필요합니다. 자세한 내용은 [Mac 문서](macos/README.md)를 참고하세요.

## 검증과 보안

Windows 빌드 경고·오류 0개, 단위 테스트 **111개 통과**. Mac의 C 통신 검증 테스트, Apple silicon·Intel 네이티브 CI 빌드와 임시 서명 검사를 수행했습니다. Mac에서 앱을 실행한 결과나 두 장치 간 호환성을 확인한 결과는 아닙니다. [테스트 결과](TEST-RESULTS.md)에 실제 장치 확인 항목을 구분했습니다.

신뢰하는 기기끼리만 사용하세요. 전환 시 민감한 클립보드 텍스트도 전달될 수 있으며 회사 정책을 지켜야 합니다. 관리자 앱, 로그인·보안 화면 등은 지원 범위 밖이고 보안 감사를 완료한 제품이 아닙니다. 설정과 로그는 Windows의 `%LOCALAPPDATA%\MouseBridge`에 남습니다.

MIT는 수정·재배포·상업적 이용을 허용하며 저작권·라이선스 표시 유지가 필요합니다. 원본 소스는 [MIT](LICENSE), 포함된 외부 구성 요소는 각자의 라이선스를 따릅니다.

Mac0.3.1은 서비스 검색 시간 초과와 장치 주소 비교, 늦은 콜백 무시, **Copy connection diagnostics** 버튼을 추가했습니다. 네이티브 빌드와 모의 장치 테스트는 통과했으며 실제 연결 성공 여부는 다시 시험해야 합니다. Windows는0.3.0 그대로 사용할 수 있습니다.

Mac0.3.2는 필요할 때 인증을 요구하는 기본 Bluetooth 연결을 먼저 만든 후 서비스 검색을 시작합니다. 기본 연결·검색·RFCOMM 단계를 구분해 진단합니다. 네이티브 모의 장치 테스트는 통과했으며 실제 Mac–Windows 문제 해결 여부는 재시험이 필요합니다. Windows0.3.0은 그대로 사용할 수 있습니다.
