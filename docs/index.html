GOOD TO KNOW

Small details. Clear expectations.

Does it need the internet?

No shared Wi-Fi, VPN or internet is required for device-to-device use. Downloading the app and source uses the internet.

What moves between computers?

Keyboard and mouse input, plus plain Unicode text copied before switching. Files, images and formatting are not shared.

Why leave the corners alone?

Only the middle 80% of a facing edge switches computers. Top and bottom 10% remain available for corner and taskbar actions.

What about permissions and trust?

Use only trusted paired computers. Input and clipboard can be sensitive. Elevated apps, secure desktops and login screens are outside scope.

Are Mac and Windows identical?

No. The Mac preview uses fixed F8, manual reconnect and a simpler layout selector. Windows has custom shortcuts and indicator customization. IME/key layouts need hardware tests.

Is it signed or security-audited?

No. These are experimental, unsigned builds, not a security-reviewed remote administration product. Use the normal OS review process; do not disable system protections.
