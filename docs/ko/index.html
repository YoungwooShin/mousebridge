사용 전에 알아두세요

작은 차이도, 분명하게.

인터넷이 필요한가요?

컴퓨터 간 사용에는 같은 와이파이, VPN, 인터넷이 필요하지 않습니다. 앱과 소스를 내려받을 때는 인터넷을 사용합니다.

무엇을 옮길 수 있나요?

키보드·마우스 입력과 전환 전에 복사한 일반 유니코드 텍스트를 전달합니다. 파일, 이미지, 글자 서식은 공유하지 않습니다.

모서리는 왜 제외하나요?

맞닿은 경계의 가운데 80%에서만 넘어갑니다. 위아래 10%는 작업표시줄이나 모서리 버튼을 누를 수 있도록 남겨 둡니다.

권한과 보안은 어떤가요?

신뢰하는 컴퓨터끼리만 페어링하세요. 입력과 클립보드에는 민감한 내용이 있을 수 있습니다. 관리자 앱, 보안 화면, 로그인 화면은 지원 범위 밖입니다.

Mac과 Windows 기능이 같나요?

아닙니다. Mac 실험 버전은 F8 고정, 수동 재연결, 간단한 좌우 선택을 사용합니다. Windows에는 단축키·경계 표시 사용자 설정이 있습니다. 한영 전환과 키 배열은 실제 테스트가 필요합니다.

서명이나 보안 검증이 되어 있나요?

아직 아닙니다. 보안 감사를 마친 원격 관리 제품이 아닌, 서명되지 않은 실험 빌드입니다. 운영체제의 정상적인 확인 절차를 사용하고 보안 기능을 끄지 마세요.
